## 🔄 如何切换到其他领域

```bash
# 1. 清空当前数据
rm *.txt custom_dict.txt

# 2. 放入你的知识库文件
#    支持格式：.txt / .md / .pdf
#    每行一条知识，或按段落自然分割

# 3. （可选）添加自定义分词词典
#    创建 custom_dict.txt，每行一个词

# 4. 重新构建索引
cd ..
python -c "from Rag.vector_store import VectorStore; VectorStore().build_index('data/')"
python -c "from Rag.bm25_store import BM25Store; BM25Store().build_index('data/')"
```

## 📝 数据格式

每行一条知识记录，支持以下格式：

```
# 推荐：纯文本，每行一条
边刷不转时，先检查边刷是否被毛发缠绕，清理后重新安装即可。

# 也支持多行（段落间空行分隔）
## 故障代码 E03
E03 表示风机异常。
请检查尘盒是否安装到位，并清理风机进风口异物。
如果问题依旧，请联系售后。

# PDF 文件自动解析，无需额外格式
```
